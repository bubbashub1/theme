# Bubba Hub Design System

## Brand character

Bubba Hub should feel:
- Warm
- Friendly
- Reassuring
- Community-led
- Modern
- Calm
- Practical
- Welcoming to parents and families

Avoid an overly corporate, clinical or childish appearance.

## Typography

Display:
Playfair Display, normally weights 500, 600 and 700.

Use for:
- Hero headings
- Page headings
- Editorial statements
- Major section headings

Interface and body:
Work Sans, normally weights 400, 500, 600 and 700.

Use for:
- Body copy
- Navigation
- Buttons
- Forms
- Labels
- Metadata
- Directory controls

## Colour tokens

| Token | Value | Use |
|---|---|---|
| Ink | #3f3b36 | Main text |
| Ink Soft | #625d55 | Secondary text |
| Paper | #fbf8f2 | Main background |
| Surface | #fffdf9 | Cards and panels |
| Cream | #f4ede1 | Secondary areas |
| Sage | #dfe9df | Feature areas |
| Sage Deep | #567064 | Supporting colour |
| Peach | #efc6b5 | Warm highlights |
| Coral | #d98270 | Primary action |
| Gold | #d9ad63 | Small highlights |
| Line | #e6ded2 | Borders |
| White | #ffffff | Contrast surfaces |

Components should reference design tokens rather than scattering raw colours throughout stylesheets.

## Shape

Suggested corner language:
- Small controls: 12–14px
- Cards: about 18px
- Feature panels: about 28px

Use rounded corners consistently without making every element a pill.

## Buttons

Buttons need:
- Clear labels
- Comfortable touch targets
- Visible hover and focus states
- Coral for key actions
- Sage or neutral treatments for secondary actions

Do not rely on colour alone for active, selected or disabled states.

## Cards

Directory and dashboard cards should normally have:
- Surface background
- Soft border
- Rounded corners
- Subtle shadow
- Consistent internal spacing
- Clear heading hierarchy
- Obvious primary action

## Search

Search is a major Bubba Hub experience and should support:
- Keyword
- Location/region
- Category
- Free groups
- Term-time filtering
- Advanced search
- Directory/calendar consistency

Controls must work with mouse, keyboard and touch.

## Navigation

Desktop navigation should be clean and spacious.

Mobile navigation must:
- Avoid tiny tap targets
- Prevent horizontal overflow
- Keep key destinations easy to reach
- Maintain clear active states
- Work with Directory and My Hub

## Calendar

The calendar should feel familiar and calm.

Support:
- List
- Today
- Week
- Previous/next navigation
- Mobile day-by-day presentation
- Clear time columns
- Session cards
- Term-time handling
- Fortnightly/monthly schedules

Print styling should support A4 output and avoid unnecessary blank pages.

## My Hub

My Hub should feel like a personal family dashboard.

Use:
- Clear section headings
- Friendly empty states
- Large touch targets
- Calm cards
- Strong distinction between actions and information

The theme should provide the visual treatment for My Support Requests and message replies while the plugin remains responsible for messaging functionality.

## Imagery

Prefer authentic community imagery:
- Families
- Parents and babies
- Local groups
- Activities
- Community spaces
- Friendly natural photography

Avoid generic corporate stock imagery where possible.
